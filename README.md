# BotsInc reborn

This project contains the new implementation of the turtle bot used in the acclaimed book "Squeak: Learn programming with Robots" (https://www.amazon.com/dp/1590594916?lv=shuf&channelId=500&plpRedirect=mhFallback).
This implementation is working on top of Pharo 14 and Bloc/Toplo, the new graphical framework.
